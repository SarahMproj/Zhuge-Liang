# Vision

## The thesis

Zhuge Liang is a library of executable strategic patterns for AI agents.

The project begins from a simple premise: stories can carry operational intelligence. The most durable stories about Kongming persist because they compress difficult strategic ideas into memorable forms—patience before commitment, leverage under scarcity, indirect acquisition, disciplined counsel, political alignment, continuity of mission, and adaptation under uncertainty.

The goal is not to imitate Zhuge Liang's speaking style. The goal is to translate meaningful patterns from his historical record and literary legend into protocols that change how agents behave.

## What this project is

A stratagem in Zhuge Liang should include:

1. A clearly identified source story or character pattern.
2. A strategic principle that can be stated without mysticism.
3. A portable agent protocol.
4. Structured inputs and outputs.
5. Failure modes and boundaries.
6. Evaluations that test whether the protocol improves outcomes.

A stratagem may be expressed as a skill, prompt protocol, MCP capability, state machine, schema, reference implementation, or evaluation harness.

## What this project is not

Zhuge Liang is not:

- a roleplay chatbot;
- a collection of decorative Three Kingdoms names;
- a claim that every literary episode is historical fact;
- a generic orchestration framework with renamed components;
- a substitute for evidence, safety, or human judgment.

## The strategic character

The project should emphasize the full character of Kongming rather than reducing him to clever tricks.

Core themes include:

- **Foresight:** understand the field beyond the immediate task.
- **Preparation:** create the conditions for success before action begins.
- **Leverage:** use timing, information, and structure to overcome resource disadvantages.
- **Logistics:** protect supply lines, continuity, and execution capacity.
- **Counsel:** state risks and duties clearly, especially before consequential action.
- **Adaptation:** update plans when assumptions fail.
- **Alignment:** distinguish coerced compliance from durable commitment.
- **Stewardship:** serve the mandate rather than the strategist's ego.

## Product direction

The initial release focuses on portable specifications and examples. A future implementation may include:

- a CLI for invoking stratagems against local artifacts;
- an MCP server exposing stratagem tools and resources;
- adapters for agent frameworks;
- a benchmark suite for strategic behavior;
- a registry for community-contributed stratagems.

The first implementation target is **Borrowed Arrows**: an adversarial synthesis protocol that converts criticism into tests, requirements, risks, research questions, and improvements.

## Standard stratagem lifecycle

```text
Source story
    -> strategic interpretation
    -> protocol specification
    -> structured artifact
    -> reference implementation
    -> evaluation
    -> field evidence
```

## Quality bar

A proposed stratagem should answer four questions:

1. Would this still be useful without the story?
2. Does the story materially improve how the protocol is understood or executed?
3. Can another agent or developer implement it from the specification?
4. Can we test whether it helps?

The ideal answer is yes to all four.
